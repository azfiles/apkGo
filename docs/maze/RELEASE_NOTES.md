下载 **Pipi-Maze-Garden-0.1.0.apk**，在 Android 手机上打开并允许安装。需要 Android 7.0+、OpenGL ES 3.0；包含 ARM64、ARMv7 和 x86_64，横屏游玩。

《Pipi Maze · 花园捉迷藏》是一款 Godot 2.5D 迷宫探索游戏：沿用 `pipi-maze` 的布朗、屁屁侦探和小考拉原图，把寻找小考拉的主题做成立体花园与纸片角色的可玩首版。

- 晨光花园、池畔回廊、暮色林地，三个完整原创关卡。
- 点击浅色小路自动寻路，也可用触屏方向盘、方向键或 WASD 连续移动。
- 每关三枚可选自然印记，发现全部三枚可获得三星；到达小考拉即可完成。
- 不限时；支持局部提示、暂停、后台自动暂停、音效开关和各关本机进度保存。

附件包含 Android APK、完整 Godot 工程 ZIP、Linux x86_64 试玩 ZIP、操作说明、截图、验证记录和 SHA-256 校验文件。工程使用 **Godot 4.6.3**，导入 `maze-godot/project.godot` 后按 F5 运行。

发布前执行迷宫规则与存档测试、Godot 三维场景和完整三关物理通关测试、导出 Linux 游戏的系统输入测试、APK 签名与对齐检查。**Android APK 尚未经过真机安装和操作体验验证**；本次作为试玩版发布。详细范围和构建观察见 `verification.tar.gz`。

游戏使用独立包名 `com.alex.pipimaze.garden` 和仓库已有公开演示签名。离线运行，无账号与联网权限。角色原图版权归原权利人，来源及权利声明随工程保存；本项目为非官方个人兴趣原型，场景、迷宫与自然印记为原创适配。
