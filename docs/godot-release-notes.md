## 循光 · 流动数字 / Godot 2.0

下载 **Schulte-Flow-Godot-2.0.0.apk**，在 Android 手机上打开并允许安装。需要 Android 7.0 / API 24 及以上、OpenGL ES 3.0。包含 ARM64、ARMv7 和 x86_64。

保留舒尔特表按顺序找数字的玩法，加入 Godot 刚体数字球、球体与边界碰撞反弹、点击推动、碰撞火花、点亮粒子、通关庆祝。9 个关卡从 3×3 逐步增加到 5×5，并逐步提高漂流速度；支持星级、下一关解锁、最佳纪录、暂停隐藏、后台停表、进度恢复和音效/触感开关。

这个版本使用独立包名 `com.alex.schulteflow.godot`，可以与旧版并存；旧版成绩不迁移。应用离线运行，仅申请振动权限，不含广告与统计。

发布门槛：Godot 逻辑测试、真实场景输入/碰撞/关卡测试、APK 签名和对齐验证、Android 10 模拟器上安装并触摸操作发布 APK、截图中可见游戏画面且没有 Godot 渲染错误。验证报告和设备截图随 `verification.tar.gz` 提供。全部关卡通关验证在 Godot 场景测试中进行；Android 设备冒烟验证启动、暂停、恢复、重开、后台及进程重启恢复。未声称完成所有机型、实体触感或听感测试。
