# 灯火遗迹：第三人称探索设计

本版解决上一版正交俯视 + 纸片角色缺少空间感的问题。以独立原生 Godot 项目重建第三人称探索，不沿用旧版点击寻路和 2D 角色表现。

## 一局体验

玩家从灯光围合的小庭院出发。附近地面、石墙和路灯提供空间尺度，布朗的橙棕色皮肤、格纹蓝帽和黄色挎包在薄荷绿庭院中保持辨识度。沿路发现可自动收集的星星，抵达支路灯塔时需要主动点亮；音阶、晶体反馈、光柱和 HUD 同时确认结果。点亮三座灯塔后，归途门开启流动的青金色光面。到门前主动进入，显示用时、星星、引路次数与星级。

主线目标为三座灯塔，支线奖励为十二枚星星；不设置失败计时。三章规模为 11×11、13×13、15×15；固定种子让复玩和缺陷复现稳定。深度优先生成骨架，入口加入小庭院，再加入少量环路。目标通过图距离拉开，所有目标和可选收集物都可达。

## 交互原则

动态摇杆支持左侧舒适落点；移动方向随当前镜头朝向变化。右侧独立追踪手指旋转视角，可与移动同时进行。冲刺平滑加速并消耗可恢复体力。镜头使用固定距离平滑跟随和墙体局部消隐，避免死角把镜头推入角色内部。

只在近距离显示点灯/出口按钮；不会隔墙点亮或自动完成主线。引路灯给出接下来六格合法路线，而非直接搬运角色。地图只显示已探索区域；暂停、地图、失去焦点与 Android 返回键都停止移动，避免触控残留。

## 美术与工程边界

0.4.0 使用奶油黄、薄荷绿、帽子蓝和蜂蜜金，配合圆润石块、树冠、云朵、花朵和柔和远山。拾取物是有厚度、圆角和高光的五角星，UI 的收集计数与结算星级沿用同一轮廓。浅色纸张面板和深绿色文字覆盖首页、HUD、暂停、地图及结算。

布朗采用共同 Body 节点及有重叠体积的颈部，修复分离头身；加深头、帽、身体和衣裤，保持侧面体积。新增肘膝屈伸、起跳收腿、下落伸腿、落地缓冲，四组面部几何呈现微笑、开心、惊讶和专注，眼睛有定时眨眼。模型与场景均导出独立 GLB，保留 Blender 原文件和生成脚本，详细说明见 BROWN.md 与 ART.md。

本版是小型探索体验版，没有战斗和敌人。0.3.0 在原有迷宫上加入跳跃挑战，保留固定种子、目标位置及旧存档兼容性。

## 跳跃与挑战

跳跃初速 6.8、重力 18，腾空约 0.76 秒、最高约 1.28 米，低于完整石墙的 2.35 米。支持离边 0.10 秒宽限和落地前 0.12 秒输入缓冲，不支持二段跳或按住自动连跳。暂停不积分物理，也不清除空中速度；重开和后台切换清除排队输入。

沿既有路网的直线走廊放置交替的矮石栏与断桥；两侧必须是安全格，且避开入口、出口、灯塔和星星位置。三章分别 3 / 5 / 7 处，栏高 0.55 / 0.65 / 0.75 米，桥缝 1.0 / 1.2 / 1.4 米。断桥使用分离的地面碰撞体，无法直接步行通过。地图以金色线标石栏、蓝色线标断桥，场景用金色边线和附近提示说明起跳。

每章 2 / 3 / 4 枚星星升至 2.05 米，拾取使用三维距离，因此走到正下方不会自动收集。掉落后回到最近经过的安全格，所有点灯和收集状态保留；不会因失败重复发奖或清空进度。

## 首页人物查看

复用场景中的布朗模型与灯光，以独立的展示镜头参数支持整周环绕、俯仰及有界缩放。拖动后停留在用户选择的角度，自动旋转需主动开启；回正恢复正面构图。触屏双指捏合与鼠标滚轮共用缩放约束，开始与选章按钮不参与旋转手势。路灯、树木和石墙使用相同的镜头遮挡消隐，保持角色可见。

0.4.0 首页增加圆形展示台和表情预览按钮；操作按钮避开人物躯干，保持正侧背面都可查看。
