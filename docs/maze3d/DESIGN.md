# 灯火遗迹：第三人称探索设计

本版解决上一版正交俯视 + 纸片角色缺少空间感的问题。以独立原生 Godot 项目重建第三人称探索，不沿用旧版点击寻路和 2D 角色表现。

## 一局体验

玩家从灯光围合的小庭院出发。附近地面、石墙和路灯提供空间尺度，身上的暖黄色外衣在冷色遗迹中保持辨识度。沿路发现可自动收集的萤光，抵达支路灯塔时需要主动点亮；音阶、晶体反馈、光柱和 HUD 同时确认结果。点亮三座灯塔后，归途门开启流动的青金色光面。到门前主动进入，显示用时、萤光、引路次数与星级。

主线目标为三座灯塔，支线奖励为十二枚萤光；不设置失败计时。三章规模为 11×11、13×13、15×15；固定种子让复玩和缺陷复现稳定。深度优先生成骨架，入口加入小庭院，再加入少量环路。目标通过图距离拉开，所有目标和可选收集物都可达。

## 交互原则

动态摇杆支持左侧舒适落点；移动方向随当前镜头朝向变化。右侧独立追踪手指旋转视角，可与移动同时进行。冲刺平滑加速并消耗可恢复体力。镜头使用固定距离平滑跟随和墙体局部消隐，避免死角把镜头推入角色内部。

只在近距离显示点灯/出口按钮；不会隔墙点亮或自动完成主线。引路灯给出接下来六格合法路线，而非直接搬运角色。地图只显示已探索区域；暂停、地图、失去焦点与 Android 返回键都停止移动，避免触控残留。

## 美术与工程边界

暖金色角色 / 灯火、青灰石墙、薄雾和低多边形远山形成统一配色。角色包含可摆动的四肢、呼吸和围巾运动；模型采用命名节点层级，便于后续绑定骨骼和替换动画。所有模型导出为独立 GLB，并保留 Blender 原文件和确定性生成脚本。

本版是小型探索体验版。没有战斗、跳跃、敌人和复杂机关；后续内容应基于设备试玩反馈决定，先确认移动、视角和点灯的基本手感。
