# Pipi Maze · 灯火遗迹 0.2.0 · 3D 体验版

真正的第三人称 3D 迷宫：原创立体角色、透视跟随镜头、双指移动与环顾、体力冲刺、灯塔点亮和传送门结算。

- 三章完整探索：初光庭院、回声回廊、星眠深境。
- 每章 3 座灯塔与 12 枚可选萤光；引路光迹、探索地图、三星评价。
- 角色动作、脚步/点灯/收集音效、环境音乐、震动反馈。
- 自动存档、暂停和后台保护，画质与镜头灵敏度设置。
- 独立 Android 包名，可与上一版共存；离线运行，无账号、网络或存储权限。
- 附带完整 Godot 源码、11 个 GLB 模型与 Blender 原文件。

下载 `Pipi-Maze-Ruins-0.2.0.apk` 安装，Android 7.0+，需支持 OpenGL ES 3.0。

体验包使用公开演示签名。当前验证覆盖自动通关、桌面渲染及发布流水线所列的 Android 检查；未经过 Android 真机手感、帧率或续航测试。截图来自游戏实际渲染。
