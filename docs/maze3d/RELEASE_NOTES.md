# Pipi Maze · 灯火遗迹 0.3.0 · 跳跃挑战与角色查看

基于 0.2.1 布朗角色版，加入跳跃探索和首页全方位角色查看。

- 空格或右侧「跳跃」按钮起跳，可同时移动、冲刺和转动镜头；包含腾空姿态、起跳音效与落地反馈。
- 三章分别配置 3 / 5 / 7 处矮石栏和断桥，金色起跳线与附近提示帮助判断距离。障碍高度和断桥宽度逐章增加，普通移动加跳跃即可通过。
- 每章 12 枚萤光中，分别有 2 / 3 / 4 枚需要跳起收集；原有三座灯塔、出口与星级规则保持一致。
- 断桥有真实缺口；掉落自动返回最近的安全落脚点，保留已点亮灯塔和已收集萤光。空中暂停保留速度，空中存档恢复至安全地面，兼容旧版存档。
- 首页可拖动查看人物正面、侧面和背面，上下拖动改变俯仰；支持滚轮、双指和加减按钮缩放，以及自动旋转和回正。遮挡镜头的路灯与石墙会局部消隐。

安装 `Pipi-Maze-Ruins-0.3.0.apk`。包名 `com.alex.pipimaze.ruins` 与演示签名沿用 0.2.x，可覆盖安装并保留原有进度。Android 7.0+ / OpenGL ES 3.0，离线运行，仅震动权限。

布朗沿用 0.2.1 的非官方重建模型，独立角色包仍为 `Brown-Character-0.2.1.zip`。角色版权归原权利人，素材说明见 `docs/maze3d/BROWN.md`。

本地验证与设备验证范围见 `docs/maze3d/VERIFICATION.md`；未完成的设备检查不视为通过。
