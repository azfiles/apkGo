# Pipi Maze · 灯火遗迹 0.2.1 · 布朗角色更新

将 0.2.0 的小熊探险家替换为依据《屁屁侦探》官方角色立绘重建的布朗 3D 同人模型。现有三章迷宫、场景、界面与操作方式继续沿用。

- 宽脸垂耳、黑色圆眼、小鼻子与带尖牙的笑脸。
- 蓝色格纹报童帽、白衬衫、背带短裤、黄色挎包和短袜黑鞋。
- 头部、四肢、双耳及挎包的轻微行走动作；完整背面建模。
- 附带独立 Brown-Character-0.2.1.zip：GLB、可编辑 Blender 源文件、重建脚本及四视角实际渲染。
- 包名与签名沿用 0.2.0，可覆盖安装并保留原有进度。

下载 Pipi-Maze-Ruins-0.2.1.apk 安装。Android 7.0+ / OpenGL ES 3.0，离线运行，仅震动权限。体验包使用公开演示签名。

参考：[官方角色介绍](https://oshiri-tantei.com/character/?char=char-brown)、[第 44 话官方剧照](https://oshiri-tantei.com/story/story44.html)。角色版权归 © トロル・ポプラ社／おしりたんてい製作委員会及相关权利人；此模型为非官方重建，不是官方原始模型。场景与游戏机制为本项目制作。

发布前验证包括三关连续通关、Android 模拟器安装与操作、签名及包结构检查。尚未进行实体手机帧率、功耗及手感测试。
