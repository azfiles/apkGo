# Pipi Maze · 灯火遗迹 0.5.0 · 星桥水庭与数据建模

带着布朗走进第四章「星桥水庭」，同时加入实时帧率显示和可编辑的数据关卡流水线。

- **实时 FPS**：默认显示实际绘制帧率，每 0.5 秒刷新；暂停菜单可开关，偏好会随存档保留。
- **第四章「星桥水庭」**：19×19 布局、五个区域、三处跨水桥、喷泉中庭、凉亭与高架引水渠。新增 18 颗星星、9 处跳跃挑战和 5 枚高处星星；落入水道会返回安全落脚点。
- **Blender → GLB → JSON → Godot**：模型目录保存资源 ID、源文件、根节点和简化碰撞；JSON 保存关卡通路、目标、环境及场景摆放，便于手工编辑和脚本生成。
- **8 个新模型**：拼花地砖、石桥、拱门、石柱、喷泉、凉亭、花槽、高架引水渠；连同原模型共 23 个 GLB，新增可编辑 `starbridge_library.blend`。
- **统一手工导出**：`export_models.py` 按资源 ID 从 Blender 源库导出指定模型，保留局部原点，检查布朗的 14 个动作节点。
- **旧存档兼容**：前三章通道和目标顺序保留；存档新增稳定 `level_id`，星级与收集界面支持不同章节的星星数量。

安装 **`Pipi-Maze-Ruins-0.5.0.apk`**。Android 7.0+ / OpenGL ES 3.0；离线运行，仅震动权限。versionCode 升为 500，包名与既有演示签名保留，可覆盖安装 0.3.0 / 0.4.0 并保留本机进度。

发布门禁包括四章连续物理通关的 2,089 项自动检查、实际界面渲染、新场景与 FPS 触摸检查、22 项导出资源包检查，以及 Android 安装、冷启动、移动、镜头、地图、暂停、FPS 偏好、新第四章启动及冷启动恢复。具体 Android 结果和截图位于 `Pipi-Maze-Ruins-Verification.zip`，对应流水线链接附在本页末尾。

附件包含安装包、完整工程、23 个独立 GLB 与三个 Blender 源文件、角色模型、建模说明、验证记录、实际截图和 SHA256 校验文件。布朗角色和原作立绘版权归原权利人；来源与同人重建说明见 BROWN.md / ART.md。

高架引水渠为景观，当前玩法以单层通路和局部跳跃为主。尚未进行实体手机帧率与多机型测试；软件渲染和模拟器帧率不代表手机性能。已有 0.4.0 Release 和附件保留。
