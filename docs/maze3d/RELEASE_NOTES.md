# Pipi Maze · 灯火遗迹 0.6.0 · 森兰寻光

带着布朗走进第五章「森兰寻光」。本版把 Sunland 的湖区模型接入主游戏，保留已有四章与存档。

- **新的湖湾关卡**：25×25 格、三座灯塔、24 颗星星、11 处跳跃挑战、6 颗高处星星。沿环湖栈道和红栏星桥寻找归途，落水后安全复位。
- **Sunland 场景模块**：码头、白色遮棚、彩色皮划艇、湖畔营地、展亭、水杉、柳树、芦苇和长椅。11 个新增 GLB 与可编辑 Blender 源库，继续使用既有 JSON 关卡和资源目录。
- **五章选择与来源页**：首页可直接触摸选择任意章节；场景来源、OpenStreetMap 署名和许可链接可在游戏内查看。
- **兼容与性能**：保留原四章布局、目标顺序、包名、签名与旧存档；合并重复水面绘制，沿用移动端 Compatibility 渲染、帧率开关和画质设置。

下载并安装 **Pipi-Maze-Ruins-0.6.0.apk**。Android 7.0+ / OpenGL ES 3.0；versionCode 600，沿用演示签名，可覆盖旧版安装并保留本机进度。离线游玩，仅震动权限。

这是一张基于 Sunland 模块重新编排的紧凑探索关卡，不是原数公里公园的等比例地图；码头、营地和展亭为岸边景观。实体手机帧率和多机型兼容性尚未验证。

发布门禁覆盖五章连续移动、跳跃、收集、点灯与出口，真实渲染、成品资源包，以及本次 APK 的 Android 安装、触控、第五章启动、FPS 偏好和冷启动恢复。具体日志和截图见 **Pipi-Maze-Ruins-Verification.zip**，本次流水线链接见下方。

附件包含新版 APK、完整源码、34 个 GLB、四个 Blender 源库、角色模型、验证证据、实际截图和 SHA256 校验文件。场景改编及复现说明见 **SUNLAND.md**。
