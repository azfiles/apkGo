# Pipi Maze · 灯火遗迹 0.4.0 · 布朗焕新与星光庭院

在 0.3.0 跳跃版上更新角色、美术与启动图标。

- **布朗立体建模**：补齐颈部并连接头、躯干与共同的身体节点，加深头部、格纹帽、衬衫、短裤和挎包，修复头身分离和侧面扁平的问题。
- **连贯跑跳**：新增肘、膝关节；按实际速度交替摆臂与屈膝，跳跃区分起跳收腿、下落伸腿和落地缓冲，耳朵与挎包跟随摆动。
- **四种表情**：待机微笑和眨眼、冲刺专注、腾空惊讶、收集星星和点灯开心；首页表情按钮可直接预览。
- **星光庭院美术**：立体圆角五角星取代旧光环，搭配薄荷石墙、奶油石板、圆润树冠、云朵、花朵和金色石栏标识；首页、HUD、地图、暂停和结算统一使用浅色卡通配色。
- **新版图标**：使用官方布朗立绘作为图像生成参考，保留格纹蓝帽、犬齿笑脸和黄色挎包，接入 Android 启动器与应用图标。

首页 360° 旋转、俯仰、缩放、三章跳跃挑战及旧存档继续保留。包名和演示签名不变，可覆盖安装 0.3.0 并保留进度。

安装 `Pipi-Maze-Ruins-0.4.0.apk`。Android 7.0+ / OpenGL ES 3.0；离线运行，仅震动权限。

Release 附带完整工程、Blender 源文件、独立布朗 0.4.0 模型包、实际画面、四表情与动作对照图、原尺寸新图标、验证记录和 SHA256 校验文件。布朗角色和原作立绘版权归原权利人；非官方同人重建与生成说明见 BROWN.md / ART.md。
