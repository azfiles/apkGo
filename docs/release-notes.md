## 安装
下载 **Schulte-Flow-1.0.0.apk**，在 Android 手机上打开并按系统提示允许本次安装。支持 Android 8.0 及以上，无需账号、无需联网、无广告。

## 体验
- 3×3 / 4×4 / 5×5 随机舒尔特表
- 点击回弹、粒子、连击提示、递进音效与系统触感
- 点错提示，暂停隐藏数字，切后台自动暂停
- 当前进度恢复、分难度最佳纪录、通关统计

## 验证与范围
此 Release 仅在签名验证、逻辑测试和 Android 10 模拟器冒烟测试成功后发布。测试报告随包提供，截图见对应 Actions 的 smoke-evidence。触感强度与音效听感仍需在你的实体手机上体验。

这是使用仓库内公开演示证书签名的体验版，不适合作为正式应用商店发布证书。
