# Blender 源文件与模型设计

先读 [仓库约定](../../AGENTS.md)、[建模规范](../../docs/maze3d/MODELING.md)、[布朗设计](../../docs/maze3d/BROWN.md) 与 [美术来源](../../docs/maze3d/ART.md)。本目录保存长期可编辑的源文件，不作为 Godot 运行时依赖。

## 造型与资产约定

- 保持明快卡通方向、圆润且有厚度的真实几何，沿用奶油、薄荷、天空蓝和蜂蜜金配色。角色的正、侧、背面均需成立；复杂度优先来自模块组合、区域和空间层次。
- 布朗保留橙棕犬脸、垂耳、蓝色格纹帽、白衬衫、背带短裤和黄色挎包。面部、衣物与身体保持三维体积和连接，不退回面片角色或用面部图片代替几何。
- 保持源根节点 `Brown`，以及 14 个动作节点：`Body`、`Torso`、`Head`、`ArmL`、`ArmR`、`ElbowL`、`ElbowR`、`LegL`、`LegR`、`KneeL`、`KneeR`、`EarL`、`EarR`、`Satchel`。
- 保留 `FaceSmile`、`FaceJoy`、`FaceSurprise`、`FaceFocus`、`EyeL/R` 与 `BrowL/R`，以及现有父子层级、关节原点、头颈与身体的重叠连接。当前使用刚性部件动画，骨骼蒙皮属于需要同步运行时与验证的架构迁移。
- 源文件使用米制、Z-up，布朗朝向 -Y；GLB 显式转换为 Y-up。场景模块的局部原点用于落地与拼接，源库编辑排列的位置不进入游戏。
- 新模块具有稳定资源 ID 和源根节点，在 `maze3d/assets/model_catalog.json` 登记源文件、根节点、GLB 与简化碰撞。来源、参考与改编范围记录在美术资料中，不把推定侧背设计宣称为官方设定。

## 手工编辑与交付

- 用 Blender 4.3+ 打开对应 `.blend`，保留可编辑材质与层级；按稳定 ID 用 `scripts/maze3d/export_models.py` 导出选定模块。操作步骤见建模规范。
- 手工编辑后保护源文件；程序化重建会覆盖对应源库与 GLB，运行前读 [工具约定](../../scripts/maze3d/AGENTS.md)。已提交的手工成果同样不能无意重置。
- 修改源模型时一并交付对应 GLB；新增模型一并更新资源目录，几何变化影响通行时更新简化碰撞。不要只交截图或仅游戏网格。
- 在 Godot 中验证最终导入的比例、方向、材质、角色动作和碰撞。布朗检查正面、三分之四、侧面、背面以及跑跳表情；关卡装饰实际走过周边通路。Blender 预览不能代替运行时验证。
