# 来源与署名

本场景的地理布局包含 © OpenStreetMap contributors 的数据。

- 来源：[OpenStreetMap](https://www.openstreetmap.org/)
- 许可说明：[OpenStreetMap copyright](https://www.openstreetmap.org/copyright)
- 数据库许可：[Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- 检索快照：2026-10-19
- 原点：WGS84 `121.5928 E, 31.3130 N`
- 数据转换：截取区域、合并水面、局部坐标投影、三角化、生成地形／护岸／道路；补建水湾和程序化植被已在元数据注明。

`data/map.geojson` 是 OSM 的提取数据库，按 ODbL 1.0 提供；修改后产生的 OSM 衍生地理数据库适用其署名及相同方式共享要求。将地图成果用于游戏画面时，请保留可见的 OpenStreetMap 署名和许可链接，例如在游戏制作名单／地图资料页中。完整数据库义务以许可原文为准。

建议署名：

> 场景地理数据 © OpenStreetMap contributors，ODbL 1.0。森兰场景为基于开放地图与公开资料的艺术化重建。

树木、长椅、路灯、帐篷、码头及简化建筑的几何由本仓库脚本生成，没有引入第三方下载模型或纹理。参考摄影／视频的作者、原文与访问状态见 [docs/SOURCES.md](docs/SOURCES.md)。这些参考图片和视频不随资产发布。
